Comment nous rejoindre ?

Vous retrouverez ici un guide pour rejoindre notre communauté.

1. Créer un compte

Rendez-vous sur le site officiel du jeu et cliquez sur "S'inscrire", puis suivez les instructions pour enregistrer votre compte.

Cette étape est obligatoire, même si vous passez par Steam, car ce compte vous permettra de vous connecter aux serveurs de jeu SS14 demandant une authentification, comme c'est le cas pour Station Harvest.

2. Télécharger le jeu

Rendez-vous sur le site officiel du jeu et cliquez sur "Télécharger", puis suivez les instructions pour installer le jeu sur votre ordinateur. Le jeu est disponible pour Windows, Mac ou Linux

Le jeu est aussi disponible gratuitement sur Steam ! Pratique pour profiter de l'expérience SS14 sans effort.

3. Rejoindre le serveur

Lancez le jeu et cliquez sur "Serveurs", puis recherchez "Station Harvest" dans la liste des serveurs disponibles. Cliquez sur "Rejoindre" pour vous connecter au serveur et commencer à jouer !

Vous pouvez aussi rejoindre le serveur directement via l'IP :

176.31.27.180
